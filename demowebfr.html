1. HTML5 Fundamentals

HTML (HyperText Markup Language) forms the skeleton of any website. It defines the structure using various elements and tags.

Basic Document Structure

Every HTML5 document requires a standard boilerplate:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>My First Web Page</title>
  </head>
  <body>
    <h1>Hello World!</h1>
    <p>This is a basic paragraph.</p>
  </body>
</html>

2. Modern CSS & Flexbox

CSS (Cascading Style Sheets) styles structural elements. Flexbox makes alignment and responsive layouts straightforward.

Centering Elements with Flexbox

Use Flexbox to effortlessly align elements horizontally and vertically:

.container {
  display: flex;
  justify-content: center; /* Horizontal alignment */
  align-items: center;     /* Vertical alignment */
  height: 100vh;
  background-color: #f4f4f9;
}

.box {
  padding: 20px;
  background: #007bff;
  color: white;
  border-radius: 8px;
}

3. JavaScript Interactivity

JavaScript gives web pages life and interactivity by manipulating the DOM (Document Object Model) and responding to user actions.

DOM Manipulation & Events

Example of updating text content when a button is clicked:

// Select the DOM elements
const button = document.querySelector("#myBtn");
const heading = document.querySelector("#heading");

// Add an event listener
button.addEventListener("click", () => {
  heading.textContent = "You clicked the button!";
  heading.style.color = "#28a745";
});
